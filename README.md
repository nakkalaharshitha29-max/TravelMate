# ✈️ TravelMate

TravelMate is a responsive travel planning website that helps users discover destinations, plan trips, calculate travel budgets, check destination weather, save favourite destinations, and make travel bookings.

## 🌍 Features

- 🏠 Responsive Home page
- 🗺️ Popular travel destinations
- 🔍 Destination search
- 🏖️ Destination category filters
- ❤️ Favourite destinations using Local Storage
- 📖 Destination details popup
- 📝 Travel booking form
- 🔗 Frontend and Flask backend integration
- 💰 Travel budget calculator
- 🗓️ Trip planner
- 🌤️ Destination weather information
- 📩 Contact form
- 📱 Mobile navigation menu

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python

### Storage
